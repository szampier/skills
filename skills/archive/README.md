# Archive

Skills for querying and working with the [ESO Science Archive](https://archive.eso.org).

| Skill | Description |
|-------|-------------|
| [eso-tap-obs](./eso-tap-obs/SKILL.md) | Query `ivoa.ObsCore` via TAP. Translates natural language into ADQL, TAP sync URLs, and ESO Science Portal links. |
| [astroquery-eso](./astroquery-eso/SKILL.md) | Query the ESO Science Archive using the `astroquery.eso` Python API. Covers raw, Phase 3, and instrument-specific data; downloading; calibration retrieval. |
